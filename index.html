START / 位置とメッセージだけ

つながる仕組みを、小さく。

相手の位置を受け取る。
「撃った」を送って、相手の画面で弾を出す。

スターターを読み込もう

Aのスターター ↓Bのスターター ↓
  1. ペアでA・Bを決め、自分のファイルを保存。
  2. スモウルビーを開く ↗。
  3. 左上の ファイル → コンピューターから読み込む。
  4. 保存した A_スターター.sb3 または B_スターター.sb3 を選ぶ。
Aは青・下側

Aが青を動かすと、Bの画面の青が動きます。

Bは赤・上側

Bが赤を動かすと、Aの画面の赤が動きます。

緑の旗を押し、ステージを一度クリック。← →で移動、スペースで自分の弾が出ます。最初は相手に届きません。これから3か所だけつなぎます。

STEP 1 / 接続

Aのグループに、Bが参加する。

  1. メッシュの接続画面が出たら、その画面を使う。出なければ左下の拡張機能から メッシュ を選ぶ。追加済みの場合は接続ボタン。
  2. 教員が指定した、ペア専用の ドメイン を2人とも同じにする。
  3. Aは メッシュのホストになる（グループの作成）。
  4. Bは メッシュに参加する（グループに参加） からAのグループを選ぶ。
  5. 1ペアのグループには、AとBを1つずつ接続する。

✓ 2人とも緑の旗。まだ「相手」が動かなくてOK。次で位置を受け取ります。

STEP 2 / 位置を受け取る

「相手」のx座標に、センサー。

  1. 右下のスプライト一覧で 相手 をクリック。
  2. 「ずっと」の中の x座標を0にする を探す。
  3. 左側の メッシュ をクリック。
  4. 緑の （　）センサーの値 を作業スペースへ運ぶ。
  5. ▼から、Aの人は B_x座標、Bの人は A_x座標 を選ぶ。
  6. そのブロックを、青いブロックの 0の入力欄 に入れる。
赤い枠の「ここ」が今回の変更箇所。ブロックの内側への入れ方も、完成見本と同じです。
A側の「相手」の完成図
B側の「相手」の完成図

B側は A_x座標 にします。xは横 ↔、yは縦 ↕です。変えるのはx座標。

自分のx座標を変数へ入れる処理は用意済みです。メッシュがその変数を共有し、相手がセンサーで読みます。

✓ Aの青→Bの青。Bの赤→Aの赤。両方向に反映されたら成功！ 少し遅れて動きます。

STEP 3 / 撃ったと伝える

「Aが撃った」「Bが撃った」を送る。

  1. 右下の 自分のビーム をクリック。
  2. 「もしスペースキーが押されたなら」の中の 自分へ行く を探す。
  3. 作業スペースの左側に、用意された黄色い Aが撃った を送る（B側は Bが撃った を送る）を探す。
  4. その 「送る」ブロック を取り、「自分へ行く」と「表示する」の間に入れる。
  5. ▼からAの人は Aが撃った、Bの人は Bが撃った を選ぶ。名前は準備済みです。
赤い枠の「ここ」が今回の変更箇所。ブロックの内側への入れ方も、完成見本と同じです。
A側の「自分のビーム」の完成図
B側の「自分のビーム」の完成図

「送って待つ」ではなく「送る」を使います。このメッセージもメッシュで相手へ届きます。

STEP 4 / 受け取って動く

メッセージを受け取ったら、弾を出す。

  1. 右下の 相手のビーム をクリック。
  2. 一番上の帽子形ブロック ○が撃った を受け取ったとき を見る。A側はB、B側はAが最初から選ばれています。
  3. ▼を開き、Aの人は Bが撃った、Bの人は Aが撃った が選ばれていることを確認する。

AAが撃ったBが撃った
BBが撃ったAが撃った
赤い枠の「ここ」が今回の変更箇所。ブロックの内側への入れ方も、完成見本と同じです。
A側の「相手のビーム」の完成図
B側の「相手のビーム」の完成図

A側では、相手の弾が下へ進むので y座標 < -175、進む量は -2 です。B側では上へ進むので y座標 > 175、進む量は 2 になります。

この動きは用意済みです。先頭のメッセージ名を確認すればOKです。帽子形ブロックの上には、別のブロックをつなげません。

✓ Aが撃つ→Bで青い弾。Bが撃つ→Aで赤い弾。「当たった！」まで試そう。

PLAY / 確かめる

動く・撃つ・当たる。

  1. 2人とも緑の旗を押す。Gキーや準備の操作は不要。
  2. ステージを一度クリックし、← →で移動する。
  3. スペースで撃つ。自分の弾が消えてから1秒後に、次を撃てる。
  4. 相手の画面にも弾が出るか確認する。
  5. 相手から届いた弾が自分に触れると「当たった！」と表示される。
この版の範囲

メッシュには約1秒単位の更新・待ち時間があります。相手の弾は、メッセージが届いたときに画面上の「相手」の位置から出します。そのため、発射時刻や位置が両画面で完全に一致する仕組みではありません。

ライフ・勝敗・受信確認・通信状態の管理は入れていません。まず、変数とメッセージで相手に働きかける仕組みを確かめます。

入力は半角：-2、2、0.03、0.05。「ー２」「０．０３」は使いません。メッセージ名と変数名は用意されたものを▼から選びます。

HELP / 3か所だけ確認

困ったら、ここを見る。

症状確認するところ
自分が動かない緑の旗を押し、ステージをクリック。← →を押す。
相手が動かない同じメッシュのグループ？ STEP 2で「相手」の0をセンサーに変えた？
自分の弾しか見えない送るのは自分のメッセージ、受け取るのは相手のメッセージ。STEP 3・4を両側で確認。
センサーの名前が出ない接続を確認し、両側の旗を押して数秒待つ。▼を開き直す。
弾が遅れる・途中で消える通信の遅れや、次の同名メッセージによる再実行の可能性。速い連射は避ける。

テスト用に余分に開いた作品は接続しません。接続し直したら、両方とも旗を押して、まず位置が届くか確かめます。

REFERENCE / 完成見本

共有変数は、各自1個。

Aの完成見本 ↓Bの完成見本 ↓

各作品の共有変数は A_x座標 または B_x座標 の1個だけです。画面に変数一覧や状態表示は出しません。

スターターとの差は、①センサーを1個入れる、②「送る」を1個追加、③受け取るメッセージ名を確認する、の3点です。

説明できたら、今日のゴール

① 自分の位置は、どうやって相手へ届く？
② 「撃った」を受け取ると、相手の画面で何が動く？

内部処理は通信を模したテストで確認します。実際の学校回線での動作は、完成見本を2台で開いて事前に確かめてください。
